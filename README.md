# DESENVOLVE · Pessoas & Potencial

Protótipo de plataforma de testes comportamentais da PIRAHY Alimentos: os colaboradores respondem a avaliações (DISC, Temperamentos, Perfil Animal, VAK, Mapa de Maturidade Emocional e Fit Cultural PIRAHY) e já veem o próprio perfil na hora; o RH acompanha campanhas, pessoas, grupos e relatórios num painel próprio.

## Como usar

**Direto pelo navegador (sem baixar nada):** https://angelicaaguirre-svg.github.io/desenvolve-pessoas-potencial/

**Ou como arquivo local:** o app também é um único arquivo HTML autônomo — não precisa de instalação, servidor nem build. Basta baixar `desenvolve-plataforma-v3.9-link-campanha-portatil.html` e abrir direto no navegador (duplo clique ou arrastar para uma aba).

Todos os dados (cadastros, campanhas, respostas e resultados) ficam salvos no armazenamento local do próprio navegador (`localStorage`), por navegador/computador — nada é enviado a nenhum servidor. A partir da V3.9, o **link de participação de cada campanha** (botão "Copiar link", na tela de Campanhas) carrega os dados da campanha embutidos nele mesmo, então funciona em qualquer navegador/computador que o abrir — não só no navegador de quem criou a campanha.

## Conteúdo atual

A base inicial já vem com os 6 colaboradores reais que fizeram o teste DISC pela SolidES, com os resultados reais importados. O RH pode criar novas campanhas, cadastrar mais pessoas e coletar respostas reais normalmente pela própria tela do app; também é possível editar ou excluir qualquer cadastro pela tela de Pessoas.

## Aviso

Este repositório é **público** (para permitir o link direto do GitHub Pages) e o arquivo contém dados reais de colaboradores (nomes, e-mails e resultados de DISC) dos 6 colaboradores de DISC/SolidES. Qualquer pessoa com o link consegue ver esses dados reais pelo painel de RH — decisão consciente da PIRAHY para viabilizar o teste com outras pessoas. Se isso deixar de ser aceitável, o caminho é remover esses 6 registros reais (pela própria tela de Pessoas → Editar/Excluir) antes de manter o link público, ou voltar o repositório para privado.
